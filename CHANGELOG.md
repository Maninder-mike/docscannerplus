# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-01-18

### Added

- Initial release of DocScanner Plus.
- Document scanning using Google ML Kit.
- OCR text extraction.
- Local document storage using Isar.
- Biometric authentication (App Lock).
- Dark mode support.
- PDF generation and sharing.
- Multi-selection and batch operations.
- Onboarding flow.
- Welcome notification.
- Firebase integration (Crashlytics, Analytics, Remote Config, Messaging).
